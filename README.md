# DevTime

공부 시간을 기록하고 학습 습관을 관리할 수 있는 학습 타이머 서비스입니다.

이 프로젝트는 Prokit에서 제공하는 백엔드 API, 디자인, 요구사항을 기반으로 프론트엔드를 구현한 프로젝트입니다.

---

## 링크
- Demo : https://dev-time-phi.vercel.app/

## 기술 스택

- Frontend : React, TypeScript
- Styling : Tailwind CSS
- 상태관리 : Zustand

---

## 주요 기능

### 1. 공부 타이머

- 공부 타이머 시작 / 일시정지 / 종료
- 페이지 이동 및 새로고침 이후에도 타이머 상태 유지
- 실제 경과 시간을 기반으로 타이머 계산

### 2. 할 일 관리

- 공부 시작 시 오늘의 목표 설정
- 공부 중 할 일 추가 / 수정 / 삭제

### 3. 학습 시간 기록

- 공부 종료 시 학습 기록 저장
- 총 공부 시간 기록

### 4. 날짜별 공부 시간 관리

- 자정을 기준으로 학습 시간을 분리
- 날짜별 공부 시간 통계 관리 가능

## 핵심 기술

### 1. 새로고침 이후에도 유지되는 타이머

#### 문제

일반적인 타이머는

- 페이지 새로고침
- 페이지 이동
- 브라우저 탭 비활성화
  상황에서 **타이머 상태가 초기화되거나 정확도가 떨어지는 문제**가 있습니다.

#### 해결

Zustand의 `persist` 기능을 사용하여 타이머 상태를 `localStorage`에 저장하도록 구현했습니다.

저장되는 상태

- seconds
- timerId
- studyLogId
- startTime
- lastUpdateTime
- splitTimes

```ts
persist(
  (set) => ({ ... }),
  {
    name: "timer-storage",
    storage: createJSONStorage(() => localStorage),
  }
)
```

이를 통해 페이지가 새로고침되더라도 타이머 상태를 복구할 수 있도록 설계했습니다.

#### 결과

- 페이지 새로고침 이후에도 타이머 상태 유지
- 공부 중 데이터 손실 방지

### 2. 자정을 기준으로 학습 시간을 분리하는 구조

#### 문제

공부 시간이 자정을 넘어가는 경우 단순 누적 방식으로는 **날짜별 학습 시간을 정확하게 기록**할 수 없습니다.

#### 예시

`23:50 ~ 00:30` 은 총 공부 시간은 40분이지만 날짜 기준으로 보면 나누어야 합니다.

```
1월 1일 -> 10분
1월 2일 -> 30분
```

#### 해결

학습 시간을 단순 누적하지 않고 `splitTimes` 데이터 구조를 설계하여 **날짜별 학습 시간을 분리하여 관리**하도록 구현했습니다.

```ts
splitTimes = [
  {
    date: "2026-01-01T00:00:00.000Z",
    timeSpent: 600000,
  },
  {
    date: "2026-01-02T00:00:00.000Z",
    timeSpent: 1800000,
  },
];
```

#### 결과

- 자정 이후에도 학습 시간이 정확하게 분리
- 날짜 기반 학습 통계 관리 가능
